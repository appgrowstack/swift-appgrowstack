# Contributing

This repository is a published copy. The package is developed in a private monorepo, and each
release is copied here with its tag.

- **Issues and discussion** are welcome here. Include the smallest example that reproduces the
  problem, your Swift and Xcode versions, and the platform.
- **Pull requests** are read, but not merged here. A change we take is re-applied upstream and
  arrives in this repository with the next release.

Versions follow [Semantic Versioning](https://semver.org) with bare tags (`1.2.3`, no `v`). While
the major version is 0, a breaking change bumps the minor version.
